# Submission checklist

## Before sharing

- [ ] Extract or open the project folder and run `python chatbot.py`.
- [ ] Demonstrate a greeting, `how are you`, an unrecognized phrase, and `bye`.
- [ ] Read through the code so you can explain it in your own words.
- [ ] Replace `[Your Name]` in the video script and repository placeholder in the LinkedIn draft.

## GitHub

- [ ] Sign in to GitHub and create a **public** repository named `CodeAlpha_Basic_Chatbot` (the PDF's naming pattern is `CodeAlpha_ProjectName`).
- [ ] Upload the contents of this project folder, including `chatbot.py`, `README.md`, and supporting materials.
- [ ] Confirm the repository page opens while signed out or in a private browser window.
- [ ] Copy the public repository URL for the post and submission form.

## LinkedIn

- [ ] Record a short video showing the program running and explaining the code.
- [ ] Attach the video to a LinkedIn post based on `linkedin_post_draft.md`.
- [ ] Add the public GitHub URL and tag @CodeAlpha if required.
- [ ] Publish the post yourself and save its URL.

## CodeAlpha form

- [ ] Open the submission form shared in your internship WhatsApp group.
- [ ] Enter the requested personal and internship details.
- [ ] Submit the GitHub repository URL and LinkedIn video post URL (and any other fields the form requests).
- [ ] Save the form confirmation or submission receipt.

## Eligibility note

The supplied PDF states that two or three tasks are required and that one task is incomplete. The later WhatsApp notice in the referenced conversation says a special relaxation accepts at least one task for the deadline on 10 November 2026, subject to submission and verification. Confirm the current rule and any deadline changes with the official group/form; keep a copy of the notice. This package does not guarantee certificate or LOR eligibility.
